The Spend Ladder

A video-making agent that lives as one HTML file in this repo. It asks a handful of questions, plans the film, and then stops five times to look you in the eye — each time immediately before it is about to spend real money, and never after.

$0.75 one second of premium generated motion

Veo 3.1 Standard, per second of output. That single second costs more than the entire narration track of a twenty-minute film — and more than thirty-seven generated stills.

$0.08 one minute, composited, second film onward

The path this repo already runs. Eight films in, the cast is drawn and paid for, so a new film costs a few plates and a render. The ratio between these two numbers is the whole design.

Which project is this film for?

A project is the durable thing: a product, its asset library, its voice, its typefaces, its editorial rules, and every film ever made under it. A film is an instance of a project and inherits all of it without being asked. This runs before G1, costs nothing, and every asset it finds is one that G3 and G4 never have to draw.

03
Why the gates sit where they sit

  
Not evenly spaced through the process — bunched immediately before each order-of-magnitude
  jump in what a mistake costs. Everything above a gate is cheap to redo. Everything below it is not.


  
    
    
  1. G1 · One sentence. Before any prose exists. The message, the audience, the badge, the
    archetype. Costs nothing, decides everything — three drafts of a Bizzing Bee episode were written
    because two of them started at the script and skipped this.
    2. 
    
  2. G2 · Script and shot list. Every beat with its measured runtime and its own price tag,
    so an expensive shot is visible as a number before it is a picture. You cut beats here; rephrasing
    them bought 12 words once, cutting them bought 530.
    3. 
    
  3. G3 · The look — two images, then stop. This is the gate that saves the money.
    One model sheet, one hero plate, at full size. If the hand is wrong you have spent ten cents
    instead of eight dollars. Every character this repo has drawn since is anchored on a sheet
    generated first, because the one film that skipped it came back with an airbrushed elephant beside
    a flat-shaded monkey and one cell that was inexplicably gold.
    4. 
    
  4. G4 · The contact sheet. Every asset on one page before a single frame renders. This is
    the gate that saves the evening. Today it caught a log drawn end-on, a yard that grew trees and
    moved the camera, a house whose roof changed shape when it was repaired, and a "golden" goose that
    was a lemon rubber duck.
    5. 
    
  5. G4½ · One second. Motion archetypes only. Before ninety seconds of generated video,
    buy one. Seventy-five cents against sixty-seven dollars, and it answers the only question
    a still cannot: does it move like the thing it is meant to be.
    6. 
    
  6. G5 · The cut. A still from every shot, then the preview. Rendered, not remembered —
    check the timestamps, because a cut that predates a note is indistinguishable from the note being
    ignored, and that has cost a whole evening before.
    7. 
  






  
04
The agent is a state machine, not a chat box

  
A chat box re-derives what it already knew on every turn, and pays for it in tokens.
  Each state below loads only its own slice of the brief, calls a model sized to the job, and hands
  back a patch for a human to accept.


  

    

      
Brief
brief.json ← the console

      
The dropdowns above, plus the one sentence. Written to disk before any model is called, so the
      whole production is a file in git rather than a conversation nobody can find.

    

    

      
Script
plan.js · check-voice.py

      
Beats, cue phrases, runtime measured from the narration rather than guessed. Refuses a story
      whose voice track fails the batch check, and flags anything sacred for a person.

    

    

      
Look
gen-assets.py --only sheet

      
Exactly two calls. Model sheet first, always — a borrowed cast pays nothing here, which is why
      film eight cost one character and film four cost none.

    

    

      
Assets
gen-assets.py · gild.py

      
The rest of the library, content-hash cached. Re-running an unchanged prompt costs nothing;
      derived art (a gold cell from a white one) is computed, never re-drawn.

    

    

      
Rig
build.js → shot pages

      
Picks primitives from the library the eight films built: carry · ride · rock · troop ·
      scale · world · count · many. Structural truths go here, where they cannot be expressed
      wrongly.

    

    

      
Check
film.js --check

      
Assertions measured off the live DOM before a frame exists. An exit code, not something a
      person has to notice. This is the step no other video tool has.

    

    

      
Render
film.js · cut.js

      
Per-shot cache and a pid lock. One changed shot costs one render. Picture and sound are
      gated against each other before a master is written.

    

    

      
Ship
publish.sh · released.json

      
The 720p preview goes to a content-addressed URL. The master never enters git. What actually
      shipped is recorded, because that is the one fact the repo cannot rebuild.

    

  


  

    

      
Five mechanics that keep the token bill down

      
1. The agent does not look at pictures. Assertions are code. A passing check returns one
      line of text, not an image — vision calls happen only when a check fails or a gate opens.

      
2. Contact sheets, not files. Twelve assets judged in one vision call instead of twelve.

      
3. The brief is the context. Each state reads its own slice, never the transcript.

      
4. Cache on content, not names. Same prompt and same references, no call.

      
5. Escalate by stage. A cheap model lays out shots; the expensive one writes the script
      and judges the contact sheet.

    

    

      
Two things the ledger makes true rather than hoped-for

      
Every call appends one line: what it cost, what it produced, and which gate authorised
      it. An unauthorised call is a bug that shows up in an audit rather than in a bill.

      
And each adapter declares its own price, so the forecast on the console and the ledger at the
      bottom read from the same number. A forecast that drifts from the invoice is worse than no
      forecast, because people stop reading it.

05
The editor edits the film, not the video

  
A timeline that writes JSON. Drag a boundary and it moves a narration cue, not a
  stretch filter; swap an asset and one shot re-renders. There is deliberately no re-timing step,
  because a timestamp rots the moment a sentence changes and a cue phrase does not.


  

    

      
What a click does

      
Trim or reorder → rewrites scenes.json, re-renders the shots that moved.

      
Swap an asset → redraws one cell, keeps the rest of the library, re-renders the shots
      that name it.

      
Re-record a line → one cue, seconds, not the whole track. Cue-level granularity is the
      entire argument for the voice pipeline being built the way it is.

      
Promote a shot to generative → the clip turns orange on the timeline and the forecast
      jumps by a visible amount before you confirm. Expensive things should look expensive.

    

    

      
What it refuses

      
Stretching a shot to fit audio. Deleting an assertion to make a render pass. Publishing a
      master over the size cap. Rendering two copies of one film at once. Each of those is a real
      evening that was lost once, and each is now an exit code.

      
None of this is new work — it is the pipeline that already made eight films, given a front
      door and a price tag.

    

  






  
What this proposal is not

  
It is not built. Nothing here calls an API yet; the console above is a working mock with real
  rates behind it, so the shape can be argued with before any of it is written. The costs are from
  published August 2026 rates and will move.

  
The differentiator, if it is worth building: every other tool in this
  space will generate. None of them will refuse. This one already knows how to say no to a
  film where two geese are not both holding the stick.
